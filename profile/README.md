# CycoNerd Security Labs

Frontline 21st Century Security & Privacy Defense Research.

CycoNerd Security Labs is a private R&D organization focused on
defensive technologies that help individuals detect, analyze,
and understand modern surveillance threats in physical environments.

## Active Projects

- **CycoNerd Security Tricorder v1**
  A handheld, computer-vision–driven privacy defense scanner combining
  optical, infrared, and AI-assisted analysis.

## Repositories

- `tricorder-v1-docs` — System architecture, specifications, threat models
- `tricorder-v1-firmware` — Embedded firmware (Raspberry Pi Pico)
- `tricorder-v1-host` — Windows host application
- `tricorder-v1-cv-ml` — Computer vision & ML pipelines

## Status

All projects are under active private development.
Public releases will be announced when appropriate.
